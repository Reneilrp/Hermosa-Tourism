Core Functionality Matrix

Feature-by-Feature Deep Dive

Detailed breakdown of how each feature operates, what the Web UI and Mobile UI look like, who interacts with them, and their exact operational impact.

01 Place & Mosque Directory (Halal & Cultural Map)

Comprehensive GIS mapping of accredited Halal eateries, historical masjids, and cultural landmarks.

Heritage & Places
💻 Web Admin UI Tourism Registry Clerk & Officers
  • Directory Management: Add, edit, and filter landmarks, restaurants, and masjids across Zamboanga.
  • Halal Tier Badging: Assign Tier 1 (NCMF Certified) or Tier 2 (Muslim-Owned / Halal Friendly) status.
  • Facility Auditing: Log prayer room availability, separate ablution stations, and wheelchair accessibility.
  • Interactive Coordinates: Visual GPS coordinate mapping and real-time category filtering.
📱 Mobile App UI Tourists, Pilgrims & Local Residents
  • Interactive Map: Real-time distance calculation, category pills (Mosques, Food, Heritage), and directional routing.
  • Verified Details: Contact phone numbers, operating hours, Halal certification numbers, and user ratings.
  • Ablution & Amenity HUD: Instant visibility into running wudu facilities and dedicated female prayer areas.
  • 1-Tap Navigation: Direct walking and driving directions to any verified destination.

02 Packages & Bookings (Dynamic Catalog & Guide Dispatch)

Tour booking queue management and real-time dispatch of accredited multilingual guides.

Live Data Parity
💻 Web Admin UI Chief Tourism Officer & Dispatchers
  • Dynamic Package Editor: Edit pricing (₱6,500, ₱2,400, Free), duration, and inclusion bullet points for Packages A, B, and C.
  • Instant Mobile Reflection: Admin edits instantly update the mobile booking catalog in real-time.
  • Bookings Queue: Review incoming inquiries with pax count, travel dates, and dietary requests.
  • 1-Click Guide Dispatch: Assign accredited guides with language tags (Tausug, Chavacano, Arabic, English).
📱 Mobile App UI Pilgrims & Accredited Tour Guides
  • Interactive Package Selector: Explore Package A (All-Inclusive), Package B (Flexi-Pass), or Package C (DIY Free).
  • Instant Booking Modal: Select travel date, number of pax, and submit inquiry directly to the City Tourism Office.
  • Tour Guide Dispatch Cockpit: Dedicated screen for assigned guides showing tourist roster, itinerary stops, and contacts.
  • Real-Time Status: Travelers see assigned guide profile, photo, badge accreditation, and phone number.

03 MSME Halal Onboarding & Self-Declaration Queue

Democratized, low-barrier intake pipeline for local Muslim-owned street food, satti grills, and cafes.

Governance & Inclusivity
💻 Web Admin UI City Halal Compliance Auditors
  • Audit Intake Queue: Review incoming MSME applications from Basilan, Zamboanga City, and Sulu.
  • Affidavit Verification: Inspect legal self-declarations (strictly no pork, alcohol, segregated cookware).
  • Status Transitions: 1-click status update (`Pending` ➔ `Under Audit` ➔ `Approved`).
  • Auto-Publish to Mobile: Approved vendors automatically get the green "Tier 2 Verified" badge on the tourist map.
📱 Mobile App UI Local Food Vendors & Street-Food MSMEs
  • Public Intake Portal: Clean, mobile-friendly 4-step wizard to apply with zero bureaucratic fees.
  • Kitchen Affidavit: Checkboxes declaring meat supplier, kitchen segregation, and musalla availability.
  • Application Tracking: Track application status using an assigned tracking number (e.g., `MSME-2026-001`).
  • Tourist Visibility: Once approved, the stall displays photos, signature dishes (e.g., Tausug Satti), and phone number.

04 Mosque Facilities & Ablution (Wudu) Inspector

Physical technical audits for Masjids, prayer facilities, and water cleanliness standards.

Islamic Affairs
💻 Web Admin UI Islamic Affairs Inspectors & Field Auditors
  • Ablution Water Verification: Audits masjids for continuous running potable wudu water.
  • Female Section Inspection: Verifies dedicated, segregated female prayer halls with privacy curtains.
  • Qibla Precision Mihrab: Logs compass-calibrated orientation toward the Kaaba in Mecca.
  • Facility Amenities: Air-cooling, visitor parking, wheelchair ramps, and historical NHCP markers.
📱 Mobile App UI Muslim Pilgrims & Traveling Families
  • Filter Masjids by Amenity: Filter specifically for masjids with running water wudu or female halls.
  • Mosque Detail Sheet: View prayer capacity, Friday Jumuah prayer times, history, and photography.
  • Qibla Compass HUD: On-screen compass calibrated to Zamboanga GPS coordinates pointing to Mecca.
  • Wudu Status Feedback: Pilgrims can submit community reports on current water flow and cleanliness.

05 Low-Bandwidth Island Offline Sync & Export

Zero-connectivity offline database bundles engineered for remote cultural trails and low-connectivity zones.

Island Resiliency
💻 Web Admin UI System Administrators & Field Officers
  • Sync Bundle Engine: Compresses all POIs, cultural packages, and emergency contacts into an ultra-lean JSON payload.
  • Registry Export: Generates official printable PDF reports and CSV datasets for City Council and DOT.
  • Sync Monitoring: Tracks offline version hashes to ensure field devices receive timely delta updates.
📱 Mobile App UI Backpackers, Island Travelers & Solo Explorers
  • 1-Click Offline Download: Pre-cache the entire Zamboanga database before heading off-grid.
  • Zero-Signal Navigation: Access maps, tour packages, emergency contacts, and mosque wudu info without signal.
  • Automatic Delta Sync: Seamlessly checks for changes when re-entering Wi-Fi or cellular coverage.
End-to-End Real-Time Pipelines

How Web and Mobile Work Together

Four real-world operational workflows demonstrating seamless two-way data synchronization between Web Admin officers and Mobile travelers.

Workflow A: Package Editing & Live Mobile Reflection

Admin updates package inclusions or prices on the Web Admin; mobile travelers see the new details immediately.

1

Web Admin Edits

Admin opens Packages & Bookings on Web, clicks "Edit Package A", and updates price or inclusion perks.

2

Laravel Cloud API

Database updates `tour_packages` table and invalidates cached catalog responses across edge nodes.

3

Mobile App Syncs

Mobile app immediately renders the new price and inclusions without needing an App Store update.

4

Tourist Books

Tourist submits booking for the updated package directly on their phone.

Workflow B: Tourist Inquiry & Tour Guide Dispatch Pipeline

Tourist books a guided tour on mobile; Admin assigns a licensed bilingual guide; guide receives tour details on mobile.

1

Mobile Booking

Tourist selects Package A for 4 pax, inputs travel date, and submits inquiry via Mobile App.

2

Web Queue Alert

Booking appears instantly in Web Admin's Packages & Bookings queue with unread notification badge.

3

Admin Dispatches

Admin reviews inquiry and assigns an accredited bilingual guide (e.g., Ustadz Nur-Hassan Ahmad) with confirmation notes.

4

Guide Mobile Roster

Assigned tour appears directly on the Guide's Mobile App dashboard with tourist contact info and itinerary route.
